# Сөзмаржан ортақ сөз қоры

Бұл жинақ «Зертхана → Сөзсандық» бөліміне серверде сақталатын ортақ қор қосады. Бұрынғы негізгі сөздік, 192 оқулық карточкасы мен зертхана құралдары сақталған.

## Қолданушы не істейді

1. Сайтты сервердің ортақ мекенжайынан ашады.
2. «Зертхана → Сөзсандық» формасына сөз, мағына, мысал, өңір және айтушы белгісін жазады. Қажет болса, 1 МБ-қа дейін аудио тіркейді.
3. Сөз алдымен жеке браузерге сақталады. «Менің ортақ қорға ұсыныстарым» тізімінен жариялауға келісімді белгілеп, «Ортақ қорға тексеруге жіберу» батырмасын басады.
4. Сөз серверге «Тексерілуде» мәртебесімен түседі. Осы кезде басқа қолданушылар оны көрмейді.
5. Мұғалім құпиясөзбен кіріп, мағынасы мен мысалын тексереді, қажет болса түзетеді. Тексеруші белгісін және дереккөзін енгізіп мақұлдайды.
6. Мақұлданған сөз бен аудионы басқа қолданушылар «Ортақ сөз қоры» тізімінен көреді. «Жаңарту» батырмасы бар, бөлім ашық кезде 20 секунд сайын да жаңарады.

Ортақ қор бұрынғы 183 жеке атау мен 192 оқулық карточкасының санын өзгертпейді: ол бөлек, мұғалім тексеретін пайдаланушы жинағы.

## Компьютерде іске қосу

Python 3.10 немесе жаңасы қажет. Қосымша Python пакеттері орнатылмайды.

Windows-та `BASTAU_WINDOWS.bat` файлын ашуға болады. Бірінші рет мұғалімнің кемінде 12 таңбалы құпиясөзін терминалда екі рет енгізіңіз. Құпиясөз экранда көрсетілмейді.

Немесе жинақ қалтасында терминалдан:

```sh
python server.py --setup
python server.py
```

Браузерден `http://localhost:8080` ашыңыз. Сервер жұмыс істеп тұрған терминалды жаппаңыз.

## Бір желідегі басқа телефоннан көру

Сервер қосылған компьютер мен телефон бір Wi-Fi желісінде болсын. Компьютердің жергілікті IP мекенжайын біліп, телефоннан `http://КОМПЬЮТЕР_IP:8080` ашыңыз. Мысалы IP 192.168.1.20 болса, мекенжай `http://192.168.1.20:8080` болады. Операциялық жүйенің желілік рұқсаты осы портқа кіруге мүмкіндік беруі керек.

Бұл — мектептің ішкі желісіндегі жұмыс. Компьютер өшсе немесе сервер тоқтаса, ортақ қор қолжетімсіз болады.

## Интернетке жариялау

Бұл мұрағаттың өзі интернетке жарияланған сайт емес. Оны Python немесе Docker серверін іске қосатын хостингке орналастыру керек. Барлық қолданушы бір сервердің HTTPS мекенжайын ашқанда ғана ортақ базаға қосылады. HTML файлын жеке тарату ортақ базаны іске қоспайды.

Серверге мына параметрлер беріледі:

- `SOZMARZHAN_PUBLIC_ORIGIN`: нақты HTTPS мекенжайы, мысалы `https://sozmarzhan.example.kz`. Соңында `/` қажет емес.
- `SOZMARZHAN_DATA_DIR`: сақталатын диск қалтасы. SQLite базасы, модератор құпиясөзінің хэші және ұсыныстардың жабық кілті осында орналасады.
- `SOZMARZHAN_ADMIN_PASSWORD`: мұғалімнің кемінде 12 таңбалы құпиясөзі. Қызметтің жабық environment параметріне енгізіледі. Егер бұл параметр берілсе, `--setup` қажет емес.
- `PORT`: хостинг талап еткен порт; әдепкісі `8080`.

Бір сервер данасын тұрақты дискімен іске қосыңыз. SQLite базасы бар `/app/data` қалтасын уақытша контейнер дискісінде қалдырмаңыз. Сыртқы HTTPS reverse proxy сұранысты осы сервиске жібереді. `SOZMARZHAN_PUBLIC_ORIGIN` сайттың нақты мекенжайына тең болуы керек; бұл басқа сайттан жазу сұраныстарын шектейді және мұғалім cookie-ін Secure режиміне ауыстырады.

Docker үлгісі:

```sh
docker build -t sozmarzhan .
docker run --env-file server.env -p 8080:8080 -v sozmarzhan-data:/app/data sozmarzhan
```

`server.env` ішіне нақты origin мен өзіңіз таңдаған құпиясөзді жазыңыз. Бұл файлды көпшілікке таратпаңыз. Ортақ қор дайын жария сілтемеге автоматты қосылмайды; хостингті баптау жеке қадам.

## Бұрынғы сөздерді көшіру

Ескі HTML нұсқасын қолданған браузерден «Жинақты жүктеу» арқылы отбасылық сөздікті JSON файлына сақтаңыз. Жаңа сервердегі сайттан сол файлды «Жинақты ашу» арқылы енгізіңіз. Әкелінген жазбалар жергілікті ұсыныстар ретінде көрсетіледі; әр сөзді келісіммен ортақ қорға тексеруге жіберіңіз. Бұрынғы жергілікті «мақұлданған» мәртебесі ортақ қорда автоматты мақұлдау болып саналмайды.

Өшірілген не түзетуге қайтарылған ұсыныстың орнына толықтырылған жаңа жазба жасап жіберуге болады. Мұғалім де тексеру терезесінде сөзді, мағынасын және мысалын түзете алады.

## Мұғалім тексеруі

«Мұғалімнің ортақ қорды тексеруі» бөліміндегі кіру сервермен тексеріледі. Сессия 8 сағатқа дейін жарамды; «Шығу» батырмасы оны дереу аяқтайды. Қате кіру әрекеттері шектеледі. Жариялау үшін дереккөз, кері қайтару үшін себеп қажет.

Браузердегі ескі жергілікті тексеру белгісі ортақ қордағы мәртебені өзгерте алмайды. Ортақ сөзді жариялаудан алу үшін мұғалім «Жарияланған» тізімінен оны тексеруге немесе түзетуге қайтарады.

## Дерек және сақтық көшірме

Сөздер, аудио және мәртебелер `data/sozmarzhan.sqlite3` базасында сақталады. Серверді тоқтатып, бүкіл `data` қалтасының жабық сақтық көшірмесін алыңыз. Оның ішінде оқылмаған ұсыныстар мен сервер кілттері бар; көпшілікке жарияламаңыз. Сервер қайта қосылғанда сол қалтаны қолданса, база сақталады.

Қайта жіберу қайталанған көшірме жасамауы үшін әр ұсынысқа кездейсоқ код беріледі. Автордың мәртебені көру кілті оның браузерінде ғана сақталады. Браузер деректерін тазалау бұл кілтті жоғалтады, бірақ сервердегі ұсынысты өшірмейді.

Жеке қайталау жоспары, шығармашылық жұмыстар және оқушы бағалары ортақ қорда жарияланбайды: олар бұрынғыдай жеке браузерде қалады.

## Тексеру

```sh
python -m unittest discover -s tests -v
```

Тесттер екі бөлек қолданушы, мұғалімнің кіруі, сөз және аудио ұсыну, тексеруге дейін жасырын тұру, мақұлдаудан кейін ортақ тізімде көріну, жариялаудан қайтару, рұқсатсыз өзгертуге тыйым салу және бір сұранысты қайталағанда көшірме жасамау сценарийлерін тексереді. Тесттер уақытша база пайдаланады, нақты жинаққа тиіспейді.

## Railway-ға орналастыру

1. Архивті ашыңыз. GitHub-та жеке (Private) `sozmarzhan` репозиторийін жасап, осы қалтаның ішіндегі файлдар мен `public` бумасын жүктеңіз. ZIP файлын жүктемеңіз. `Dockerfile`, `server.py` негізгі деңгейде болуы керек.
2. Railway: **New Project → Deploy from GitHub repo** арқылы репозиторийді таңдаңыз. Dockerfile автоматты қолданылады; Build/Start командаларын қолмен енгізудің қажеті жоқ.
3. Қызметтің **Variables** бөліміне енгізіңіз:
   - `SOZMARZHAN_ADMIN_PASSWORD`: өзіңіз таңдаған кемінде 12 таңбалы құпиясөз;
   - `SOZMARZHAN_DATA_DIR`: `/app/data`;
   - `RAILWAY_RUN_UID`: `0` (Railway дискісіне жазу рұқсаты үшін).
4. Жоба алаңында оң батырма арқылы **Create Volume**, сайт қызметіне тіркеңіз. **Mount Path**: `/app/data`. Бір ғана қызмет данасын іске қосыңыз.
5. **Deploy** арқылы өзгерістерді қолданыңыз. **Settings → Networking → Generate Domain** арқылы HTTPS мекенжайын алыңыз. Порт сұралса, `8080` таңдаңыз.
6. **Variables** ішіне `SOZMARZHAN_PUBLIC_ORIGIN` мәнін қосыңыз: алынған `https://…up.railway.app` мекенжайы, соңында `/` белгісінсіз. Қайта Deploy жасаңыз.
7. Сайт мекенжайына `/api/health` жалғап ашыңыз: жауапта `"ok": true` болуы керек. «Зертхана → Сөзсандық» ішінен сынақ сөзін жіберіп, мұғалім ретінде дереккөзбен мақұлдаңыз. Басқа браузерден сол сөз көрінетінін тексеріңіз.

Тұрақты диск міндетті: ол сөздер мен аудиоларды қайта орналастырғаннан кейін сақтайды. Құпиясөзді GitHub-қа не чатқа жазбаңыз. Railway жоспарының лимиттері мен төлемін өз аккаунтыңыздан тексеріңіз.

Ресми анықтама: https://docs.railway.com/quick-start және https://docs.railway.com/volumes
